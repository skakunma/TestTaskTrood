Сервис Flask (Server): Это сервер, который обрабатывает запросы от пользователей. Он принимает текст, обращается к базе данных PostgreSQL для извлечения информации и использует библиотеку Spacy для обработки текста, например, для извлечения сущностей, таких как имена, места и даты.

PostgreSQL (Postgres): Это база данных, в которой хранится информация проекта. Она настроена с помощью переменных окружения, таких как имя пользователя, пароль и имя базы данных.

Сервис Spacy (Spacy): Это сервис, который использует библиотеку Spacy для извлечения сущностей из текста. Например, если на сервер отправляется текст с именами или местами, сервис Spacy может извлечь эти данные для дальнейшего использования.

Проект настроен с использованием Docker Compose, который упрощает работу с несколькими контейнерами. Все сервисы взаимодействуют между собой через сеть Docker, что позволяет им обращаться друг к другу по именам, указанным в конфигурации docker-compose.yml.

POST http://localhost:8080/process — Эта ручка обрабатывает текстовые запросы. Сервис ожидает, что будет отправлен JSON с текстом, например:

{
  "text": "Apple is looking at buying U.K. startup for $1 billion"
}
